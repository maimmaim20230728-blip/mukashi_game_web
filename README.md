# 名作の主人公になろう！

桃太郎、赤ずきん、おおきなかぶ、浦島太郎、さんびきのこぶた、ヘンゼルとグレーテル、かぐや姫、ブレーメンの音楽隊、十二支のはじまり、鶴の恩返し、アリババと40人の盗賊、北風と太陽。
おなじみの昔話を読みながら、選んだ道で結末が変わる読み物アプリです。
インストール不要・登録不要・広告なし・オフライン対応(PWA)。

**▶ アプリを開く: https://maimmaim20230728-blip.github.io/mukashi_game_web/**

## 収録内容

- 12のおはなしと、その視点ちがい(あわせて36の物語)・結末107種類
- はじめての1回目は、もとのおはなしのとおりに最後まで進みます
- 12言語(日本語・英語・ドイツ語・フランス語・スペイン語・イタリア語・ポルトガル語・オランダ語・スウェーデン語・韓国語・中国語・アラビア語)の切り替え・文字サイズ・音量の設定。選んだ言語のファイルだけを読み込みます
- 読みかけの場面と「けつまつ ずかん」は、端末内(localStorage)にのみ保存されます

## 原典と著作権について

- 収録している昔話は、いずれも著作権の切れた古い伝承(パブリックドメイン)を、
  本アプリが独自に再話したものです。特定の翻訳・絵本・映像作品の文章や設定は使っていません。
- 選ぶことで変わる分岐と、もとのおはなし以外の結末は、すべて本アプリのオリジナルの創作です。
- 文章・イラスト・音楽は、すべて本アプリのために書き下ろしたオリジナルです。
